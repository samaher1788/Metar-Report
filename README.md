5. **تقارير تفصيلية للمحطات** مع:
   - عدد التقارير لكل محطة
   - أقل رؤية مسجلة
   - أقصى سرعة رياح
   - تفاصيل زمنية لكل تقرير
6. **دعم متعدد للدول**: السعودية، الإمارات، الكويت، البحرين، قطر، عمان، الأردن، العراق، اليمن
7. **تحميل التقارير** كملفات نصية

### المميزات قيد التطوير 🚧
1. **توليد تقارير PDF احترافية** مع رسومات بيانية
2. **رسوم بيانية تفاعلية** (Charts.js):
   - توزيع الأحداث حسب الساعة
   - مقارنة بين المحطات
   - اتجاهات زمنية

## 📊 واجهات API المتاحة

### 1. جلب بيانات METAR
```
GET /api/fetch-metar
Query Parameters:
  - network: SA__ASOS (الشبكة - افتراضي: السعودية)
  - start_date: 2026-02-01 (تاريخ البداية)
  - end_date: 2026-02-02 (تاريخ النهاية)

Response:
{
  "success": true,
  "data": "CSV data...",
  "network": "SA__ASOS",
  "start_date": "2026-02-01",
  "end_date": "2026-02-02"
}
```

## 🏗️ البنية التقنية

### التقنيات المستخدمة
- **Backend**: Hono Framework (Cloudflare Workers)
- **Frontend**: HTML5 + Vanilla JavaScript + TailwindCSS
- **Data Source**: Iowa Environmental Mesonet (IEM) ASOS/METAR
- **Icons**: FontAwesome 6.4
- **HTTP Client**: Axios
- **Deployment**: Cloudflare Pages

### هيكل البيانات

#### نموذج بيانات METAR
```javascript
{
  station: "OERK",        // رمز المحطة
  valid: "2026-02-01 12:00", // وقت التقرير (UTC)
  wxcodes: "BLDU",        // رموز الظواهر الجوية
  vsby: 3.0,              // الرؤية (أميال)
  sknt: 25,               // سرعة الرياح (عقدة)
  lat: 24.95,             // خط العرض
  lon: 46.72              // خط الطول
}
```

#### رموز الظواهر الغبارية
- **DU**: غبار عالق (Dust)
- **SA**: رمال عالقة (Sand)
- **BLDU**: غبار متطاير (Blowing Dust)
- **BLSA**: رمال متطايرة (Blowing Sand)
- **DS**: عاصفة غبارية (Duststorm)
- **SS**: عاصفة رملية (Sandstorm)
- **+DS/+SS**: عواصف شديدة
- **TSDS/TSSS**: عواصف رعدية مع غبار/رمال
- **PO**: دوامات غبارية (Dust Whirls)

## 🚀 التشغيل المحلي

### متطلبات التشغيل
- Node.js >= 18
- npm

### الأوامر
```bash
# تثبيت المكتبات
npm install

# التطوير المحلي
npm run dev

# البناء
npm run build

# المعاينة
npm run preview

# النشر على Cloudflare Pages
npm run deploy
```

### إعداد PM2 (للخادم)
```bash
# بدء التطبيق
pm2 start ecosystem.config.cjs

# إيقاف التطبيق
pm2 stop dust-storm-reporter

# إعادة التشغيل
pm2 restart dust-storm-reporter

# عرض السجلات
pm2 logs dust-storm-reporter --nostream
```

## 📝 دليل الاستخدام

### 1. اختيار الإعدادات
- اختر تاريخ البداية والنهاية (افتراضي: الأمس واليوم)
- اختر الشبكة المطلوبة (افتراضي: السعودية)

### 2. توليد التقرير
- اضغط على زر "توليد التقرير"
- انتظر تحميل وتحليل البيانات (عادة 5-10 ثوانٍ)

### 3. عرض النتائج
- استعراض الإحصائيات في البطاقات العلوية
- قراءة التقرير التفصيلي للمحطات
- النقر على "عرض التفاصيل" لكل محطة لرؤية البيانات الدقيقة

### 4. تحميل التقرير
- اضغط على زر "تحميل PDF" (حالياً: تنزيل نصي)
- سيتم تحميل ملف بصيغة TXT
