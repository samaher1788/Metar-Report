## 📋 نظرة عامة

نظام ويب متكامل لتحليل بيانات METAR وتوليد تقارير احترافية عن العواصف الغبارية والرملية في المملكة العربية السعودية ودول المنطقة.

### ✨ المميزات الرئيسية

- 🌍 **تغطية إقليمية شاملة** - دعم 11 دولة في منطقة الخليج والشرق الأوسط
- 📊 **تحليل تلقائي** - معالجة وتصنيف بيانات METAR الخام
- 📑 **تقارير PDF احترافية** - توليد تقارير مفصلة بتنسيق PDF
- 🎨 **واجهة عربية** - تصميم حديث يدعم اللغة العربية بالكامل
- ⚡ **سرعة عالية** - معالجة فورية للبيانات
- 📱 **متجاوب** - يعمل على جميع الأجهزة

## 🚀 البدء السريع

### المتطلبات الأساسية

- Node.js 18+
- npm أو yarn

### التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/samaher1788/Metar-Report.git
cd Metar-Report

# تثبيت المكتبات
npm install

# بناء المشروع
npm run build

# تشغيل محلياً
npm run dev
```

### الوصول

افتح المتصفح على: `http://localhost:3000`

## 🌟 الظواهر المرصودة

- **BLDU** - Blowing Dust (غبار متطاير)
- **DU** - Dust (غبار عالق)
- **DS** - Duststorm (عاصفة غبارية)
- **SS** - Sandstorm (عاصفة رملية)
- **+DS/+SS** - Severe Storms (عواصف شديدة)

## 🛠️ التقنيات المستخدمة

### Backend
- **Hono** - إطار عمل خفيف للواجهات البرمجية
- **Cloudflare Workers** - نشر على الحافة (Edge)
- **TypeScript** - لغة البرمجة

### Frontend
- **Vanilla JavaScript** - بدون مكتبات ثقيلة
- **TailwindCSS** - تنسيقات حديثة
- **jsPDF** - توليد ملفات PDF
- **Axios** - طلبات HTTP
- **Font Awesome** - الأيقونات

### Data Source
- **Iowa Environmental Mesonet (IEM)** - مصدر بيانات METAR

## 🚀 النشر

### النشر المحلي باستخدام PM2

```bash
# بناء المشروع
npm run build

# تشغيل بواسطة PM2
pm2 start ecosystem.config.cjs

# التحقق من الحالة
pm2 status

# عرض السجلات
pm2 logs dust-storm-reporter --nostream
```

### النشر على Cloudflare Pages

```bash
# تسجيل الدخول
npx wrangler login

# النشر
npm run deploy
```
